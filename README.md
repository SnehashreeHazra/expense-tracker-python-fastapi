## ✨ Features

- ✅ Full CRUD for expenses
- 🔐 JWT authentication & authorization
- 📊 Responsive charts (monthly spending, categories)
- 📱 Mobile-first React + Tailwind UI
- ⚡ FastAPI with auto Swagger docs (`/docs`)
- 🐳 Dockerized — backend & frontend separated
- 🚀 GitHub Actions CI/CD ready

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Backend | FastAPI, Python, SQLAlchemy |
| Frontend | React, Tailwind CSS |
| Auth | JWT (JSON Web Tokens) |
| DevOps | Docker, Docker Compose, GitHub Actions |
| Database | PostgreSQL (via SQLAlchemy ORM) |

## 🚀 Getting Started

### Prerequisites
- Docker & Docker Compose installed
- Node.js (for local frontend dev)

### Run with Docker

```bash
git clone https://github.com/SnehashreeHazra/expense-tracker-python-fastapi.git
cd expense-tracker-python-fastapi
docker-compose up --build
```

- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:8000`
- Swagger Docs: `http://localhost:8000/docs`
